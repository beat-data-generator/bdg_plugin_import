# 导入插件 (bdg_plugin_import)

Beat Data Generator 插件：从文本时间戳或 MIDI 文件批量导入踩点。导入时自动新建轨道，
并把每个时间点换算成节拍位置放置踩点。

## 安装

把本目录放入 `<userData>/plugins`，重启编辑器；或在设置页打开插件目录后放入。
开发模式下也可放在宿主工程根目录的 `plugins/` 下。

## 使用

菜单「文件 → 导入…」，选择：

- **导入时间戳踩点** — 读取文本文件（`.txt` / `.csv` / `.tsv` / `.log`）。
- **导入 MIDI 踩点** — 由主进程弹出文件对话框，读取 MIDI 文件（`.mid` / `.midi`）。

## 时间戳格式

文件每行一个时间戳，空行与 `#` 开头的行会被忽略；若一行有多列，只取第一列
（支持空格 / 逗号 / 分号 / Tab 分隔）。

识别规则：

| 写法    | 含义               | 换算    |
| ------- | ------------------ | ------- |
| `1234`  | 毫秒（整数，无小数） | 1234 ms |
| `1.234` | 秒（保留精确小数）   | 1234 ms |
| `1234ms`| 显式毫秒           | 1234 ms |
| `1.234s`| 显式秒             | 1234 ms |

示例：

```
# 毫秒
1000
2500
# 秒
1.5
3.25
```

## MIDI 格式

- 解析标准 MIDI 文件（SMF，format 0 / 1；format 2 的多轨时间线按全局 tempo 处理）。
- 取所有 **Note On**（力度 > 0）事件，按 MIDI 自带 tempo 换算成绝对毫秒，
  再经 `beatOfTime` 落到当前节拍轴；支持 PPQ 与 SMPTE 时间分割。
- **每个 MIDI 轨道创建一条编辑器轨道**，命名为 `文件名 - 轨道名`（无轨道名则 `文件名 序号`）。
- **同一时刻的音符（和弦）合并为一个踩点**。

## 行为说明

- 文本导入的轨道以文件名命名（`beep.txt` → `beep`）。
- 所有踩点在同一个编辑批次里添加，可一次撤销。
- MIDI 的二进制解析在 `main.js`（Node 侧）完成，渲染层通过 `api.callMain` 调用。

## 故障排查

- 导入成功/失败都会在编辑器顶部弹出浮层提示（成功为深色、失败为红色），点击可关闭。
- MIDI 报「主进程无法加载 Node 的 fs 模块」：说明宿主主进程未向插件暴露 `require`，
  二进制解析无法进行，需要宿主支持。
- MIDI 报「主进程无法加载 electron」：宿主主进程未暴露 `electron`，无法弹出文件对话框。
  此时可在渲染层用 `api.system.pickFile` 取路径，再 `api.callMain("importMidi", path)` 传入。
- MIDI 报「未找到 Note On 音符」：文件可能只有控制/踏板事件，或音符以其它形式表达。
