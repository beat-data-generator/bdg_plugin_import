# 时间戳导入插件 (bdg_plugin_import)

Beat Data Generator 插件：从文本文件按时间戳批量导入踩点。导入时自动新建一条轨道，
并把每个时间戳换算成节拍位置放置踩点。

## 安装

把本目录放入 `<userData>/plugins`，重启编辑器；或在设置页打开插件目录后放入。
开发模式下也可放在宿主工程根目录的 `plugins/` 下。

## 使用

菜单「文件 → 导入… → 导入时间戳踩点」，选择一个文本文件即可。

## 时间戳格式

文件每行一个时间戳，空行与 `#` 开头的行会被忽略；若一行有多列，只取第一列
（支持空格 / 逗号 / 分号 / Tab 分隔）。

识别规则：

| 写法    | 含义               | 换算    |
| ------- | ------------------ | ------- |
| `1234`  | 毫秒（整数，无小数） | 1234 ms |
| `1.234` | 秒（保留精确小数）   | 1234 ms |
| `1234ms`| 显式毫秒           | 1234 ms |
| `1.234s`| 显式秒             | 1234 ms |

示例：

```
# 毫秒
1000
2500
# 秒
1.5
3.25
```

## 行为说明

- 新建的轨道以导入文件名命名（`beep.txt` → `beep`）。
- 所有踩点在同一个编辑批次里添加，可一次撤销。
- 时间戳经 `beatOfTime` 换算为节拍，落到当前 BPM 时间轴上。
